The problem

AI agents are starting to shop and pay for people. Checkouts are full of dark patterns: protection plans already ticked, passes slipped into the basket, fees that appear only at payment, amounts no line explains. India's consumer regulator lists 13 of them; the same tricks run everywhere. A person sometimes notices. An agent following instructions usually doesn't, and some pages now carry text written to instruct AI agents.

What PennyWise does

  1. You set the rules: what to buy, the most to spend, which fees are fine. Signed as an intent mandate.
  2. A Gemini agent shops one page at a time. It has no tool that can pay or approve a charge.
  3. PennyWise reads every page, numbers each trick, and a plain-code checker blocks any charge outside your rules. Only you can allow an extra fee.
  4. PayPal pays only the signed cart: it authorizes and holds the money, PennyWise reads the order back line by line, then it is captured. Any mismatch, and it's voided.

At payment, PennyWise numbers and blocks two late fees and an unexplained dollar.

How it works

The AI proposes. PennyWise checks. PayPal moves only the money you approved.

PayPal integration (sandbox)

Orders v2Through PayPal's TypeScript Server SDK (generated by APIMatic). Every approved line is an item; idempotent per authorization.
Authorize → verify → captureIntent AUTHORIZE so PayPal holds the money; PennyWise compares the order with the signed cart; capture, or void on mismatch.
Vault v3Saves the buyer's wallet so the agent can pay by itself (human-not-present). Login only at the end.
JS SDK buttonsBuyer-approved payment when autopay is off.
WebhooksVerified PAYMENT.CAPTURE.COMPLETED settles the run.

AI

Google Gemini (gemini-3.5-flash-lite) plans each page through one forced function call, from a structured brief of controls, prices and PennyWise's findings. Every action is validated against the page. A labelled backup planner (no AI) covers a page if Gemini is unavailable.

Trust model

  • Nothing the AI outputs can move money or change an amount.
  • Mandates and authorizations are HMAC-signed and single-use; money is integer cents.
  • Page text is data: instructions aimed at AI can't steer payments.
