# Rule engine spec (engineSpec 1)

This is the normative spec for both evaluators:

- TypeScript: `packages/rules/src`
- Kotlin: `apps/android/core-detect` (not built yet)

Both must produce identical `EvaluationResult` JSON for every fixture in `fixtures/cases`. The Kotlin engine is deferred until the Android phase (the Chrome extension ships first). When it lands, its tests compare against golden output generated by the TypeScript engine, so a behaviour change here must change both engines in the same commit.

## 1. Input

An `EvaluationContext`:

- `snapshot`: the current screen
- `journey`: earlier snapshots in the same journey, oldest first
- `taps`
- `sensitivity`

Missing arrays mean empty. Missing scalars mean `null`.

## 2. Derivation

Derivation is the only non-declarative step. It augments the input before any rule runs.

Let `ALL = journey + [snapshot]`. Let `S = snapshot`. Let `rank(stage)` be listing=0, product=1, cart=2, checkout=3; any other stage has no rank. `tapped` is the set of `controlId` from taps with `action = "tap"`.

### Snapshot-level: `derived`

| Field | Rule |
|---|---|
| `observedStages` | Distinct `stage` values of `ALL`, in first-seen order. |
| `startedAtStage` | `ALL[0].stage`. |
| `hasEntry`, `entryPrice`, `entryVariantLabel`, `entryCardId` | If `S.product.retailerSku` exists, take the **last** snapshot in `journey` with stage `listing` that has a card whose `retailerSku` equals it. Use that card's `price`, `variantLabel` (or null) and `id`. Otherwise `hasEntry=false` and the rest are null. |
| `currentPrice` | `amount` of the first `S.prices` entry with kind `listed`, else null. |
| `priceDelta` | `currentPrice - entryPrice` when both are non-null, else null. |
| `priceDeltaPct` | `priceDelta / entryPrice * 100` when `priceDelta` is non-null and `entryPrice > 0`, else null. |
| `variantChangedByUser` | True if any `tapped` id equals the `id` of a control with role `variant_selector` in any snapshot of `ALL`. |
| `previousTotal` | `total` of the last snapshot in `journey` with stage cart or checkout and a non-null total, else null. |

### Per item (fields added to each item of `S`)

**fees**

- `firstSeenStage`: stage of the first snapshot in `ALL` containing a fee with the same `kind`.
- `disclosedEarly`: some snapshot in `ALL` with stage listing or product contains a fee with the same `kind`.
- `isNew`: `journey` is non-empty and its last snapshot has no fee with the same `kind`.

**lineItems**

- `userTapped`: `origin = "user_tap"`, or `controlId` is in `tapped`.

**controls**

- `userTapped`: `id` is in `tapped`.
- `prominenceRatio`: for role `accept` with a `groupId` and a `style`, take the first control in `S.controls` with the same `groupId`, role `decline` and a `style`. The ratio is `p(accept) / p(decline)`, where `p(c) = width * height * contrast * (fontWeight >= 600 ? 1.25 : 1)`. Otherwise null. A `p(decline)` of 0 also gives null.

**cues**

- `observations`: number of snapshots in `ALL` containing a cue with the same `cueKey`, including `S`.
- `resetCount`: walk those cues in order and count steps where both `value`s are non-null, `value` increased, and `offerRef` is equal. Two absent `offerRef`s count as equal.
- `timesShownAfterDismiss`: for cues with a `promptId`, let `t` be the earliest `at` of a `dismiss` tap whose `controlId` equals the `promptId`. Count snapshots in `ALL` containing a cue with that `promptId` whose `firstSeenAt` (or, if absent, the snapshot's `capturedAt`) is after `t`. If there is no dismissal, the value is 0. Compare timestamps as instants.

**cards**

- `labelProminence`: when `sponsored = "labelled"` and both `sponsoredLabelStyle` and `cardTextStyle` have a `fontSize`, it is `(labelFontSize * labelContrast) / (cardFontSize * cardContrast)`. Otherwise null.

## 3. Rule evaluation

Rules run in pack order. For each rule:

1. If `minSensitivity = "high"` and the context sensitivity is `"standard"`, trace `skipped_sensitivity` against item id `*` and continue.
2. Items: if `forEach = "snapshot"`, there is one item (`S`) with id `snapshot`. Otherwise the items are the derived array in order. Each item's id is `item.id`.
3. The scope is `{ item, snapshot: S (derived), derived }`.
4. Evaluate in order:
   - `when` false → trace `when_false`
   - `requires` present and false → trace `requires_false`
   - `unless` present and true → trace `unless_true`
   - otherwise → trace `fired` and emit a finding

### Expressions

| Expression | Meaning |
|---|---|
| Operand | A literal, an array of literals, or `{var: "a.b.c"}`. A path walks objects by key and arrays by numeric index. Anything missing resolves to null. |
| `eq` / `neq` | Deep JSON equality. Numbers compare by value (1 == 1.0). |
| `gt`, `gte`, `lt`, `lte` | False unless both sides are numbers. |
| `in: [a, list]` | True if `list` is an array containing an element deep-equal to `a`. |
| `exists: path` | The value at `path` is not null. |
| `matches: [operand, lexiconId]` | The operand is a string and any regex in the lexicon finds a match, case-insensitive with Unicode case folding. Lexicons may only use syntax shared by ECMAScript and java.util.regex. |
| `all`, `any`, `not` | Usual boolean logic. `all` and `any` short-circuit. |

## 4. Emitting a finding

Templates replace `{path}` or `{path|fmt}` using the same scope.

**Value formatting**

| Value | Output |
|---|---|
| null | `unknown` |
| boolean | `true` / `false` |
| string | as is |
| integer-valued number | no decimals |
| other number | `toFixed(2)` with trailing zeros and any trailing `.` removed. Kotlin uses `BigDecimal(x).setScale(2, HALF_UP)`. |

**Formatters**

- `inr`: `₹` followed by the number, formatted as above.
- `pct`: `Math.round(x)` followed by `%`.

**Finding fields**

| Field | Value |
|---|---|
| `id` | `fc_` + lowercase hex of FNV-1a 64 (offset `cbf29ce484222325`, prime `100000001b3`) over the UTF-8 bytes of `ruleId|platform|retailerSku|stage|evidenceKey`. A null `retailerSku` is the empty string. |
| `retailerSku` | `S.product.retailerSku`, else null. |
| `elementRef` | The value at `emit.elementRef`'s path, if it is a string, else null. |
| `evidence[]` | `description` is a template. `observedValue` is the value at `observed` if it is a string, number or boolean, else null. `stage` is `S.stage`. `timestamp` is `S.capturedAt`. |
| `detectedAt` | `S.capturedAt`. |
| `subcategory` | Null when absent. |
| `disclaimer` | The fixed `DISCLAIMER` string. |
| `engineSpec` | `1`. |
| Key order | Not significant. |
